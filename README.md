# Siren Rush

A self-contained canvas racing game. Open `index.html` in a browser or deploy this repository with GitHub Pages.

## Controls

- **A/D** or **Left/Right**: steer
- **W/Up**: jump over cones
- **S/Down**: slide under overhead barriers
- On touch devices, drag the bottom control left/right; swipe up or down to jump/slide.

The HUD includes a visual fuel bar. Collect green `F` canisters to refill fuel and avoid obstacles and traffic.
